DIGITAL ASSIGNMENT 2 (DA-2) REPORT

Course: Database Management Systems | Submission Deadline: October 11

1. System Overview & Problem Statement

The Gym Management System is designed to manage day-to-day operations of a modern fitness facility. It provides comprehensive tracking of gym equipment inventory, regular equipment maintenance scheduling, member registrations and subscriptions, personal trainer assignments, daily machine utilization sessions, and financial fee collections.

2. Relational Schema & Normalization (Referenced from DA-1)

As established during DA-1, the database schema comprises 6 primary relations that satisfy Boyce-Codd Normal Form (BCNF), avoiding update, deletion, and insertion anomalies:

  • Equipment (Equipment_ID, Equipment_Name, Category, Brand, Purchase_Date, Condition, Status)
  • Member (Member_ID, Member_Name, Age, Gender, Phone, Membership_Type)
  • Trainer (Trainer_ID, Trainer_Name, Phone, Specialization, Experience)
  • Maintenance (Maintenance_ID, Equipment_ID, Maintenance_Date, Technician_Name, Cost, Remarks)
  • Equipment_Usage (Usage_ID, Member_ID, Equipment_ID, Trainer_ID, Usage_Date, Duration)
  • Payment (Payment_ID, Member_ID, Amount, Payment_Date, Payment_Mode, Payment_Status)

3. Table Definitions (DDL) & Integrity Constraints

Tables feature Primary Keys (PK), Foreign Keys (FK) with cascading updates and deletions, and constraint checks:

-- Example DDL with Foreign Key Constraint
CREATE TABLE Maintenance (
    Maintenance_ID VARCHAR(20) PRIMARY KEY,
    Equipment_ID VARCHAR(20) NOT NULL,
    Maintenance_Date VARCHAR(20) NOT NULL,
    Technician_Name VARCHAR(100) NOT NULL,
    Cost DECIMAL(10, 2) NOT NULL,
    Remarks VARCHAR(255),
    FOREIGN KEY (Equipment_ID) REFERENCES Equipment(Equipment_ID)
);

5. PL/SQL Implementation (Triggers, Procedures & Cursors)

5.1 Trigger for Automatic Equipment Maintenance State

CREATE OR REPLACE TRIGGER trg_equipment_status_sync
AFTER INSERT ON Maintenance
FOR EACH ROW
BEGIN
    UPDATE Equipment
    SET Status = 'Maintenance'
    WHERE Equipment_ID = :NEW.Equipment_ID;
END;

5.2 Stored Procedure for Safe Maintenance Logging

CREATE OR REPLACE PROCEDURE sp_RecordMaintenance (
    p_maint_id IN VARCHAR2, p_equip_id IN VARCHAR2,
    p_date IN VARCHAR2, p_tech IN VARCHAR2,
    p_cost IN NUMBER, p_remarks IN VARCHAR2
) AS
BEGIN
    INSERT INTO Maintenance VALUES (p_maint_id, p_equip_id, p_date, p_tech, p_cost, p_remarks);
    UPDATE Equipment SET Status = 'Maintenance' WHERE Equipment_ID = p_equip_id;
    COMMIT;
END;

5.3 Explicit Cursor for Pending Payment Notifications

DECLARE
    CURSOR cur_pending IS
        SELECT p.Payment_ID, m.Member_Name, m.Phone, p.Amount
        FROM Payment p JOIN Member m ON p.Member_ID = m.Member_ID
        WHERE p.Payment_Status = 'Pending';
    v_rec cur_pending%ROWTYPE;
BEGIN
    OPEN cur_pending;
    LOOP
        FETCH cur_pending INTO v_rec;
        EXIT WHEN cur_pending%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE('Pending Fee Alert: ' || v_rec.Member_Name || ' owes INR ' || v_rec.Amount);
    END LOOP;
    CLOSE cur_pending;
END;
